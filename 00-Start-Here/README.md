Lesson 00 - Your First Python Program

📖 What You'll Learn

Use the print() function.
Print text and numbers.
Perform simple calculations.
Write your first Python program.

💡 Important Notes
- Text must be inside quotation marks.
- Numbers don't need quotation marks.
- Python executes code from top to bottom.
- Every `print()` displays a new line.


🤖 AI Connection
The `print()` function is widely used when building AI applications.

You'll use it to:

- Debug code
- Inspect variables
- Check model outputs
- Display predictions
