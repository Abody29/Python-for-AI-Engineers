# Exercises – Lesson 00: Your First Python Program

> ⚠️ Before you start:
>
> Please solve these exercises **without using AI**.
> The goal is to train your problem-solving skills.
> If you get stuck, review the lesson and try again before checking the solutions.

---

# Exercise 1 ⭐

Print your first name.

Example output:

```text
John
```

---

# Exercise 2 ⭐

Print the following information, each on a separate line:

- Your name
- Your age
- Your country

Example output:

```text
John
17
USA
```

---

# Exercise 3 ⭐⭐

Use `print()` to display the results of the following calculations:

- 15 + 20
- 100 - 35
- 7 * 8
- 81 / 9

---

# Exercise 4 ⭐⭐⭐

Using only the `print()` function, display the following output exactly as shown:

```text
====================
Welcome to Python
====================
Let's start coding!
```

---

# ⭐ Challenge

Create your own welcome screen.

Requirements:

- Use at least **5** `print()` statements.
- Display your name.
- Display your country.
- Display a welcome message.
- Add a decorative border using characters such as:

```
====================
********************
####################
```

Example (Don't copy this):

```text
****************************
Welcome!
My name is John.
I am learning Python.
My goal is to become an AI Engineer.
****************************
```
